## Types

```ts
import type {
  OpenFeatureFlagDefinition,
  OpenFeatureFlagValue,
  OpenFeatureModuleOptions,
  OpenFeatureProviderConfig,
  OpenFeatureProviderType
} from '@developmentsprint/nuxt-openfeature/types'
```

| Type | Description |
| --- | --- |
| `OpenFeatureModuleOptions` | The `openFeature` key in `nuxt.config.ts`. See [Configuration](/reference/configuration). |
| `OpenFeatureProviderConfig` | One entry in `providers`. |
| `OpenFeatureProviderType` | `'in-memory' \| 'env' \| 'flagsmith' \| 'posthog' \| 'vercel'`. |
| `OpenFeatureFlagDefinition` | An in-memory flag: `{ variants, defaultVariant, disabled? }`. |
| `OpenFeatureFlagValue` | `boolean \| string \| number` or a JSON value. |
