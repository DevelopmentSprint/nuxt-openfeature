The module reads `openFeature` config from every layer in `nuxt.options._layers`. You can split configuration across layers:

```ts
// layers/base/nuxt.config.ts (parent layer)
export default defineNuxtConfig({
  openFeature: {
    providers: [
      {
        type: 'in-memory',
        flags: {
          'notifications-enabled': {
            variants: { on: true, off: false },
            defaultVariant: 'on'
          }
        }
      }
    ],
    publicFlags: { 'notifications-enabled': false }
  }
})
```

```ts
// nuxt.config.ts (final app — extends the layer)
export default defineNuxtConfig({
  extends: ['../layers/base'],
  modules: ['@developmentsprint/nuxt-openfeature']
  // No openFeature key needed — config is inherited from the layer.
})
```

## Merge rules

| Field | Merge rule |
|---|---|
| `providers` | Concatenated **app-first** across the chain. The app's providers appear first in the merged array, so they win under `FirstMatchStrategy`. Parent layers act as fallbacks. |
| `publicFlags` | Deep-merged, **child layers win** on key collision. The app overrides parent values for the same flag key. |
| `flagRouteBase` | Last-defined wins. The app's value overrides the parent's. |

## Override a parent provider

To override a flag's source in the app while keeping the parent's other providers as fallbacks:

```ts
// nuxt.config.ts — adds a Vercel override on top of parent's in-memory provider
export default defineNuxtConfig({
  extends: ['../layers/base'],
  openFeature: {
    providers: [
      // App-layer Vercel provider — appears FIRST after merge, wins for any flag it has.
      { type: 'vercel', options: { connectionString: process.env.FLAGS } }
    ]
  }
})
```

After merge: `[{ vercel }, { in-memory (from parent) }]`. Vercel takes precedence; in-memory is the fallback when Vercel doesn't have a given flag.

To replace the parent's providers entirely, set `providers: []` in a child layer — but note that empty arrays are skipped, not respected as "delete." Replacement is best handled by not extending the parent's openFeature config (e.g. extend only specific layers).
