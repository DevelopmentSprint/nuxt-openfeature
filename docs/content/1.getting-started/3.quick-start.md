This page uses the in-memory provider, which needs no account, so you can try
the module before connecting a vendor.

## Define a flag

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@developmentsprint/nuxt-openfeature'],
  openFeature: {
    providers: [
      {
        type: 'in-memory',
        flags: {
          'new-checkout': {
            variants: { on: true, off: false },
            defaultVariant: 'on'
          }
        }
      }
    ],
    // Flags the browser may read, with the value to use if every provider fails.
    publicFlags: {
      'new-checkout': false
    }
  }
})
```

::tip
`publicFlags` is the option people most often miss. A flag configured in a
provider but not listed there is never returned to the browser. See
[the publicFlags allowlist](/reference/configuration#the-publicflags-allowlist).
::

## Render with it

Use the component:

```vue
<template>
  <FeatureFlag name="new-checkout">
    <NewCheckout />
    <template #fallback>
      <LegacyCheckout />
    </template>
  </FeatureFlag>
</template>
```

Or the composable:

```vue
<script setup lang="ts">
const { enabled } = useFeatureFlag('new-checkout')
</script>

<template>
  <NewCheckout v-if="enabled" />
  <LegacyCheckout v-else />
</template>
```
