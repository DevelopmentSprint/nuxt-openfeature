# Installation

Install the module and its required peer dependencies in your Nuxt 4 project:

```bash
pnpm add @developmentsprint/nuxt-openfeature @openfeature/server-sdk @tanstack/vue-query
```

Then add the SDK for each vendor you use (see [Providers](/providers/flagsmith)).

Enable the module in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ['@developmentsprint/nuxt-openfeature']
})
```

> The module evaluates flags on the server and exposes client-safe APIs for consumption.

## Register TanStack Query

The client composables and the `<FeatureFlag>` component cache flags with [TanStack Query](https://tanstack.com/query/latest/docs/framework/vue/overview). The module does not register it for you. Add a plugin once, unless your app already provides a `QueryClient`:

```ts
// app/plugins/vue-query.ts
import { QueryClient, VueQueryPlugin } from '@tanstack/vue-query'

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(VueQueryPlugin, { queryClient: new QueryClient() })
})
```

Without it, `useFeatureFlag` throws `No 'queryClient' found in Vue context`.

## Identify the Signed-In User

To target flags by user, store the signed-in user in `useState('auth-user')`. See [Signed-In User](/getting-started/context-and-targeting#signed-in-user) for the expected shape. Without it, flags are evaluated with browser context only.

## Migrate from the Previous Scope

Version 0.2.5 continues the package under DevelopmentSprint. Replace the old dependency and update every package import and Nuxt module registration:

```bash
pnpm remove @ribrewguy/nuxt-openfeature
pnpm add @developmentsprint/nuxt-openfeature
```

Use `@developmentsprint/nuxt-openfeature` in `modules` and in imports, including any `/types` or `/runtime/` subpaths. The `openFeature` configuration key and runtime APIs are unchanged by the scope migration.
