# Installation

Install the module in your Nuxt 4 project:

```bash
pnpm add @developmentsprint/nuxt-openfeature
```

Enable the module in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ['@developmentsprint/nuxt-openfeature']
})
```

> The module evaluates flags on the server and exposes client-safe APIs for consumption.

## Migrate from the Previous Scope

Version 0.2.5 continues the package under DevelopmentSprint. Replace the old dependency and update every package import and Nuxt module registration:

```bash
pnpm remove @ribrewguy/nuxt-openfeature
pnpm add @developmentsprint/nuxt-openfeature
```

Use `@developmentsprint/nuxt-openfeature` in `modules` and in imports, including any `/types` or `/runtime/` subpaths. The `openFeature` configuration key and runtime APIs are unchanged by the scope migration.
